# Recommendation relevance review

17 November 2026 (NZ time). Desk review of SmartKai’s eight fictional scenarios using provisional-v1. Each recommendation was rated against the stated practices: 0 = unrelated, 1 = broadly relevant without a specific match, 2 = directly addresses the reported practice. For the scenario with no frequent indicators, the expected task is to provide broad prevention guidance. Scores reflect one reviewer’s judgment.

| Scenario | Recommendation(s) and score | Rationale |
| --- | --- | --- |
| No frequent indicators | General prevention (1) | Broadly useful stock, shopping and leftover advice. No frequent issue calls for targeted advice. |
| Overbuyer only | Check before shopping (2) | Checking stock and listing quantities directly addresses buying more than needed. |
| Food Forgetter only | Use-first area (2) | Making vulnerable items visible directly addresses forgetting food. |
| Poor Meal Planner only | Plan before shopping (2) | Listing upcoming meals before shopping directly addresses unplanned purchases. |
| Leftover Discarder only | Plan leftover use (2) | Assigning leftovers to a meal and adjusting portions directly addresses discarding leftovers. |
| Storage Learner only | Check storage instructions (2) | Packaging instructions provide a direct starting point for resolving storage uncertainty. |
| Multiple profiles | Check before shopping (2), use-first area (2), check storage instructions (2) | Each action corresponds to one frequently reported practice. |
| All profiles | Check before shopping (2), use-first area (2), plan before shopping (2), plan leftover use (2), check storage instructions (2) | Each frequent practice has corresponding advice. Shopping and meal advice overlap but address distinct steps. |

The review rates alignment with the questionnaire. Participant usefulness, sustained behaviour change and waste outcomes require separate evidence. The automated scenario run independently confirmed expected profile and recommendation identifiers for all eight scenarios.
